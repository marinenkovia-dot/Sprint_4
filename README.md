# qa_python
# tests.py

1. test_add_new_book_success: Использует параметризацию для проверки добавления книг с разной длиной имени, включая граничное значение (40 символов). Проверяет, что книга добавляется и её жанр изначально пуст.

2. test_add_new_book_invalid_length: Параметризованный тест для проверки защиты от некорректных данных (пустая строка и строка длиннее 40 символов).

3. test_set_book_genre_valid: Проверяет базовый сценарий установки жанра.

4. test_set_book_genre_invalid: Параметризованный тест, проверяющий два негативных сценария: попытка установить жанр для книги, которой нет в коллекции, и попытка установить жанр, которого нет в разрешенном списке genre.

5. test_get_books_with_specific_genre: Проверяет фильтрацию книг по конкретному жанру.

6. test_get_books_for_children: Проверяет, что метод корректно исключает книги с жанрами из списка genre_age_rating (“Ужасы”, “Детективы”).

7. test_favorites_add_and_uniqueness: Проверяет добавление книги в избранное и гарантирует, что одна и та же книга не может быть добавлена дважды (список остается уникальным).

8. test_favorites_add_invalid_book: Проверяет защиту: книгу нельзя добавить в избранное, если она предварительно не была добавлена в основной словарь books_genre.

9. test_delete_from_favorites: Проверяет успешное удаление книги из избранного.

10. test_delete_nonexistent_from_favorites: Проверяет устойчивость метода удаления: если попытаться удалить книгу, которой нет в избранном, программа не должна падать с ошибкой.
